The problem

Studios run on spreadsheets, messengers and memory.

Scattered tools

Schedules in one place, memberships in another, payments in a notebook. Every change means updating three systems by hand.

Booking back-and-forth

“Is there space tomorrow evening?” — the front desk answers the same questions all day, and classes still get overbooked.

Claude-powered AI assistant

Members ask in their own words. Cluvyra books the real slot.

The assistant is built on Anthropic’s Claude API and connected to Cluvyra through a small set of controlled backend tools. It understands requests like “tomorrow after 6 pm, something in a group”, checks live availability in the studio’s database and prepares the booking.

  • Only real classes. Suggestions come from the live schedule — the assistant can’t invent times or prices.
  • Rules enforced by the server. Membership type, expiry, capacity and duplicate bookings are checked by the backend, not by the model.
  • Explicit confirmation. Nothing is booked until the member taps “Confirm”; the confirmation is a one-time, user-bound server token.
  • Private by design. The assistant sees only the signed-in member’s own data and never runs arbitrary database operations.
  • Ukrainian & English. Replies in the member’s language, with general fitness guidance and no medical advice.
